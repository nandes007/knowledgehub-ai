# Screenshots

Drop the demo visuals here, then swap the placeholder note in the root
`README.md`'s "Demo" section for real `![...](...)` image tags pointing at
these files:

- `chat.png` — a conversation mid-answer, streaming, with the source
  citations visible under the response
- `upload.png` (or `upload.gif`) — the knowledge page: drag-and-drop upload,
  a document's status flipping from *processing* to *ready*
- `demo.gif` (optional) — the full loop in one clip: upload a doc → wait for
  *ready* → ask about it → cited answer streams in

Keep them reasonably small (compress PNGs, keep GIFs under a few MB) so the
README stays fast to load.
